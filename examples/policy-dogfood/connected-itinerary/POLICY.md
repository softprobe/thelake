# Travel agent policy

## Disclose a same-day onward connection before cancellation
approved: yes

Before cancelling a flight leg, the travel agent must inspect the full
itinerary. If another same-day segment is connected, it must name the affected
segment and explain the stranding risk before asking the traveler to confirm.

The trace evidence should show the itinerary lookup, the disclosure, the
traveler's confirmation, and then the cancellation action, in that order.

Source: [`source/travel-policy.md`](source/travel-policy.md), Flight
cancellation handling section.
